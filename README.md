# VRestocker
A Mineclonia mod that allows you to refresh villager trades. Made to get rare enchanted books or better deals from villagers easier.
## Info
This is a mod primary for Mineclonia, which itself is based off of Luanti(Minetest). Currently there is no other compatibilities other then that.  
All this mod adds is a simple button on the top left of the main screen. If the villager has no experience in trading yet, you can refresh the trades until you get the set you wanted. Its as simple as that.
![Example of where that button is and what it looks like](/textures/Example.png)  
### Dependencies
Dependencies: mobs_mc,mcl_util  
*These are the bare minimum. Of course it would be ideal to have the entire Mineclonia game.
